DUAN

参考实现

数值对齐用的参考脚本。每个 Burn 组件都先和这里的输出对齐，再考虑性能。

脚本用途对应阶段
qwen_ref.py用 transformers 跑 Qwen3，导出 token id、嵌入层和每一层的隐藏状态、最终隐藏状态（FP32）P2，crates/duan-qwen/tests/align.rs 读它的输出
qwen_zero_probe.pyQwen3-0.6B 零样本读选项标签 token 概率，验证因果模型的零样本读法P0，结果见 P0 实测记录
qwen_choice_probe.pyQwen3-0.6B 零样本回答 System One 格式请求里的 choice 题，按「前缀 + 标签」整段打分，可选贪心生成做核对P0，结果见 欧冠反事实对照
hf_compat.py各脚本共用的模型加载，按已安装的 transformers 版本选精度参数公共

kime 自带的参考脚本在 third_party/kime/tools/ref/，其中 train_ref.py 是写 PyTorch 参考训练器（P5）时的范本，laya_ref.py 可以导出 Laya 的输出作为对照基线。

环境

脚本不绑定机器，同一份代码在下面两种环境里都能跑。参考输出一律在 CPU 上以 FP32 计算，所以在哪台机器上导出，数值都应该一致；换机器后重新导出一次、和旧结果比对，就能确认环境没问题。

Apple Silicon、Linux、Windows： 用最新版。

uv venv -p 3.12 .venv && source .venv/bin/activate
uv pip install torch transformers safetensors numpy

Intel Mac（x86_64）： PyTorch 从 2.5 起不再发布 macOS x86_64 的 wheel，能用的最高版本是 2.2.2，它要求 Python ≤ 3.12 且 numpy < 2，transformers 也要相应停在 4.57 以下。

python3.12 -m venv .venv && source .venv/bin/activate
pip install "torch==2.2.2" "numpy<2" "transformers<4.57" safetensors
torchmacOS x86_64macOS arm64
2.5.1 及以上无 wheel有
2.2.2有有

from_pretrained 的精度参数在 transformers 4.56 从 torch_dtype= 改名为 dtype=，这取决于 transformers 版本，和 torch 版本无关。hf_compat.py 会按已安装的版本自动选择，脚本里不要直接写这两个参数。实验记录里要写上 torch 和 transformers 的版本。

导出 Qwen3 参考输出并对齐

# 权重下载到 models/，参考输出写到 data/，两处都不提交
huggingface-cli download Qwen/Qwen3-0.6B-Base --local-dir models/Qwen3-0.6B-Base
python tools/ref/qwen_ref.py --model models/Qwen3-0.6B-Base --out data/ref/qwen3-0.6b

DUAN_QWEN_DIR=models/Qwen3-0.6B-Base DUAN_REF_DIR=data/ref/qwen3-0.6b \
  cargo test -p duan-qwen --test align -- --include-ignored

不加 --cases 时用内置的 4 个样例（中文、英文、JSON 和空串）。--cases 接受每行带 text 字段的 JSON lines 文件。

输出格式：

  • cases.jsonl：每行是一个样例的 text 和 ids。
  • <i>.safetensors：一个样例的全部张量，都是 FP32、形状 [seq, hidden]：
    • embeddings：嵌入层的输出；
    • layer_<j>：第 j 层的输出，j 从 0 到倒数第二层。transformers 不单独给出最后一层在最终归一化之前的输出；
    • final：最后一层经过最终 RMSNorm 之后的输出；
    • 另有 ids，int64。

Rust 端用和权重加载器同一个 safetensors crate 来读。对比时记下 --revision 或模型快照的提交号，写进实验记录。
