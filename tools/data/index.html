中文训练数据（P3）

把中文数据集转换成 kime 的训练格式。格式、增强方式和防泄漏规则都和 kime 保持一致，参见 third_party/kime/tools/data/README.md 与 third_party/kime/spec/12-training.md。

文件

文件作用
sources_zh.json候选中文数据集清单，字段与 kime 的 sources.json 相同：name、dataset、config、revision、split、license、license_note、use、task
convert_zh.py转换器，复用 kime convert.py 的 line、choice、noul 和种子规则，输出 <out>/raw/<source>.jsonl

加入一个数据源

  1. 在 sources_zh.json 里加一条记录，固定 revision，写清许可证依据。许可证缺失、未知、非商用或仅限研究的，一律 "use": "exclude"，并在 license_note 里写原因。

  2. 在 convert_zh.py 里写一个同名函数，登记到 CONVERTERS。每个问题至少准备 3 到 4 种中文指令措辞，state 的键名也从几个候选里随机选。

  3. 运行转换：

    pip install -r tools/requirements.txt
python tools/data/convert_zh.py data/zh --only <name>

长度预算

训练和推理都按 Qwen3 分词器计长度。转换完成后统计每个数据源的 state、问题和选项的 token 数分布，据此定下各部分的预算和截断规则，写进实验记录，并填进 docs/design.md 第 3.7 节。同时用分词器确认嵌入矩阵里空着的 id 范围，填进第 3.6 节。

中文评测集

评测集只取各数据集的测试集，永远不参与训练，放在 data/zh-eval/（不提交）。训练数据进入分片之前，先用 kime contam 对评测集去重（Jaccard 0.5），再生成 manifest.json，最后用 kime eval <suite> --data-manifest <manifest.json> 检查（这个命令至少要一个 suite 路径）。这一步属于 P3 的产出，目前还没有实现（U14）。
